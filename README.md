## The 5 Templates

### 1. Minimal
Clean, whitespace-focused design. Perfect for developer tools and technical products. Inspired by Linear and Vercel's aesthetic.

### 2. Bold
Strong typography, high contrast, dark theme. Great for B2B SaaS products that want to make a statement.

### 3. Gradient
Colorful gradients, modern feel. Ideal for creative tools, design products, and consumer-facing apps.

### 4. Neon
Dark, developer-focused with vibrant neon accents. Perfect for CLI tools, APIs, and developer platforms. Code-themed UI.

### 5. Corporate
Professional, trustworthy, enterprise-ready. Great for B2B enterprise SaaS with security and compliance messaging.

---

## What's Included in Each Template

Every template comes with these sections, fully designed and responsive:

- **Navigation** — Logo, links, and CTA button
- **Hero** — Headline, subheadline, CTA buttons, social proof
- **Logo Bar** — Trusted-by section
- **Features Grid** — 3-column feature cards with icons
- **Pricing Table** — 3-tier pricing (Free, Pro, Enterprise)
- **Testimonials** — Customer quotes with avatars
- **CTA Section** — Final conversion section
- **Footer** — Multi-column footer with links

## Quick Start

```bash
git clone https://github.com/hardik139337/saas-landing-templates.git
cd saas-landing-templates
npm install
npm run dev
```

Open http://localhost:3000 to see the template showcase with live previews.

---

## How to Use

1. **Browse** all 5 templates in the interactive showcase
2. **Pick** the template that matches your product's vibe
3. **Copy** the component from `src/components/templates/`
4. **Customize** the text, colors, and images for your product
5. **Deploy** — it's a standard Next.js app

Each template is a single React component. No complex setup. Just copy and edit.
